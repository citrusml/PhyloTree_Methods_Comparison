### 1. 三角不等式違反（Triangular Inequality Violation）とは？

距離行列の任意の 3 つの Taxon $(A, B, C)$ において、理論上は以下の不等式が成り立つ必要があります：

$$d(A, C) \le d(A, B) + d(B, C)$$

しかし、確率的な変異のばらつきや、長枝（大きな進化距離 $D$）、距離の推定量誤差により、**$d(A, C) > d(A, B) + d(B, C)$** となる現象が発生します。

#### 違反が発生した場合の弊害：
- 最小二乗法（Least Squares）や BIONJ/NJ において **外枝長が負の値（Negative Branch Length）** になる。
- 距離行列で説明できる分散（Explained Variance）が大幅に低下し、系統樹推定の精度が落

---

### 2. FastME の `-q` オプションによる補正の仕組み

FastME に `-q` フラグを付与すると、**"Correcting distances accordingly..."** という補正処理が実行されます。

#### 補正のアルゴリズム（距離の距離空間化 / Smoothing）:
1. **最短経路による上限補正（Shortest-path metricization）**:
   - 違反しているペア $(A, C)$ に対して、中間ノード $B$ を経由する距離の和 $d(A, B) + d(B, C)$ を上回らないよう、距離行列の値を補正します。
2. **幾何学的平滑化**:
   - 距離行列全体が正しい距離空間（Metric Space）の制約を満たすように数理調整されます。

### 4. 実行コマンドの比較

もし実験7において FastME の三角不等式補正を有効化したい場合は、`fastme` 呼び出し部に `-q` フラグを追加します。

- **補正なし（デフォルト）**:
  `fastme -i <matrix_file> -o <outtree_file>`
- **補正あり**:
  `fastme -i <matrix_file> -o <outtree_file> -q`

2. 具体的アルゴリズム（Floyd-Warshall 法によるメトリック閉包）
FastME などのソフトウェアでは、グラフ理論の 全対最短経路アルゴリズム（Floyd-Warshall 法） を応用して距離行列を補正します。

$N$ 個の Taxon を頂点、推定された距離 $D_{ij}$ を辺の重みとする完全グラフを考えます。

処理手順:
すべての Taxon のトリプレット $(i, j, k)$ について、以下のように距離の更新（置き換え）を繰り返し行います：

$$D'{ij} \leftarrow \min \bigl( D{ij}, ; D_{ik} + D_{kj} \bigr)$$

ステップ 1: 2点間の距離 $D_{ij}$ が、別の中間点 $k$ を経由するルート $D_{ik} + D_{kj}$ よりも大きいかチェック。
ステップ 2: もし大きい（＝三角不等式に違反している）場合、$D_{ij}$ を小さい方の値 $D_{ik} + D_{kj}$ に書き換える。
ステップ 3: これを全 Taxon の組み合わせに対して $O(N^3)$ の計算量で全探索・更新する。
