## calculate_sss.py
len_seqs = 0になった時に除外するようになっているが、普通にエラーを吐くようにしてほしい。それに伴って除外処理は削除してほしい。

### 修正内容（2026-09-08 実施）

#### 1. 長さ 0 配列のエラー送出化と除外処理の削除
- **除外・パディング処理の削除**:
  - `valid_seqs = [s for s in seqs if len(s) > 0]` によるフィルタリング処理を削除。
  - 除外によって生じたペア欠損を `0.0` で埋めるパディング処理 (`scores.extend([0.0] * ...)`) を削除。
- **エラーチェックの追加**:
  - `compute_sss_for_sequences` および `compute_sss_for_fasta` の冒頭で、配列長が 0 の配列が含まれているかを検査。
  - 長さ 0 の配列が存在した場合、即座に指定のエラーメッセージで例外を送出：
    ```python
    if any(len(s) == 0 for s in seqs):
        raise ValueError("ERROR!!: this replication contains 0 length")
    ```

#### 2. 原著（Matsui & Iwasaki 2020 / Dufour et al. 2010）準拠の実装への刷新
- **MMseqs2 による all-to-all PSA ビットスコア計算の追加**:
  - 原著（Matsui & Iwasaki 2020 / `gs2` の C++ ソースコード `src/format.cpp` の `bl2mat` 関数）と完全に一致する計算ロジック `compute_sss_with_mmseqs` を実装。
  - MMseqs2 コマンド (`mmseqs createdb` -> `mmseqs search -e 10 -s 7.5` -> `mmseqs convertalis --format-mode 0`) を実行して得られたビットスコア行列 $S$ から、原著通りの対称正規化スコアを算出：
    $$w_{ij} = \frac{S(i, j) + S(j, i)}{S(i, i) + S(j, j)}$$
    （アライメントヒットが存在しないペアはスコア 0.0）
- **Bio.Align フォールバックの完全撤廃と MMseqs2 専任化**:
  - ユーザー指示に基づき、Biopython (`Bio.Align.PairwiseAligner`) によるフォールバック処理および関連引数 (`--method`, `--gap_open`, `--gap_extend`) を完全に削除。
  - MMseqs2 による論文完全準拠の計算のみを行う単一・高信頼な構成へ純化。
  - `mmseqs` バイナリが見つからない場合は曖昧にフォールバックせず、明確に `RuntimeError("ERROR!!: mmseqs binary not found. Please ensure MMseqs2 is installed and available in PATH.")` を送出して停止。
